# MyMix v2 · 测试包分发

HarmonyOS NEXT 多论坛客户端 **MyMix v2** 的**测试版本**分发仓库。

本仓库**只包含发布说明**，不含任何源代码。
安装包（`.hap`）在 **[Releases](../../releases)** 页面以附件形式提供，不占用 git 历史。

---

## 安装方式

> ### ⚠️ 先读这段：为什么不能直接安装
>
> **1. HarmonyOS NEXT 不允许直接点 `.hap` 安装。**
> 系统限制了安装途径（普通用户只能从应用市场装），在「文件管理」里点 `.hap`
> 通常会提示「无法识别文件类型」，不会触发安装。
>
> **2. 本测试包是调试签名，换一台设备就装不上。**
> 包是用开发者本地的 DevEco 调试证书签的，签名 profile（`.p7b`）里只登记了
> 开发者自己那台设备的 UDID。别人直接装会报：
> `code:9568322 signature verification failed due to not trusted app source`
> （或 `INSTALL_FAILED_APP_SOURCE_NOT_TRUSTED`）。
>
> **所以：必须用侧载工具，用「你自己的华为开发者账号」对包重新签名后再安装。**
> 下面三种方式本质都是做这件事，只是操作入口不同。

---

### 方式一：手机端自签安装（推荐，无需电脑）

1. 在鸿蒙手机上安装侧载工具 **HOKit**（鸿蒙设备选 Android 版）
2. 开启开发者模式：设置 → 关于本机 → 连续点「软件版本」直到提示已开启（会自动重启）
3. 设置 → 系统 → 开发者选项 → 打开「**无线调试**」，记下显示的 `IP:端口`
4. 打开 HOKit → 登录**你自己的华为开发者账号**（需完成实名认证）→ 连接设备（填上面的 IP:端口）
5. 选择下载好的 `.hap` → **签名安装**
6. 首次使用会引导申请调试证书、把本机 UDID 注册到你的账号下，按提示走完即可

### 方式二：电脑端侧载工具（HOKit 桌面版 / 小白调试助手）

1. 电脑安装 **HOKit 桌面版**或**小白调试助手**（Auto-Installer，开源：<https://github.com/likuai2010/auto-installer>）
2. 手机开启开发者模式 + 「**USB 调试**」，数据线连接电脑
3. 工具中登录**你自己的华为开发者账号** → 选择 `.hap` → 重签名 → 安装

### 方式三：hdc 命令行（开发者，仅当设备 UDID 已登记在签名 profile 中）

```bash
hdc -t <设备序列号> install -r MyMix-v2_v1.0.1-test.N.hap
hdc shell aa start -a EntryAbility -b com.mymixnew.myapplication
```

> - 覆盖安装请务必带 `-r`，否则会报安装失败。
> - 若报 `9568322` / `APP_SOURCE_NOT_TRUSTED`，说明**该设备 UDID 不在调试 profile 里**，
>   请改用方式一或方式二。

| 项目 | 说明 |
| --- | --- |

## 版本号规则

格式：`v1.0.0-test.N`

- `1.0.0` 对应 `AppScope/app.json5` 中的 `versionName`
- `test` 表示测试构建（`buildMode=debug`）
- `N` 为递增的测试包序号，**数字越大越新**

装包后可在 **全局设置 → 关于** 中核对：

| 项目 | 说明 |
| --- | --- |
| 版本号 | `1.0.1 (1000000)` |
| 徽标 | 橙色「测试版」= debug 构建；绿色「正式版」= release 构建 |
| 安装时间 | 该包的实际安装时刻。**装完新包后请核对这项刷新了**，否则说明没装成功 |
