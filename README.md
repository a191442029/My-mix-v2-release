# MyMix v2 · 测试包分发

HarmonyOS NEXT 多论坛客户端 **MyMix v2** 的**测试版本**分发仓库。

本仓库**只包含发布说明**，不含任何源代码。
安装包（`.hap`）在 **[Releases](../../releases)** 页面以附件形式提供，不占用 git 历史。

---

## 安装方式

### 方式一：手机直接安装（推荐）

1. 在下方 Releases 中下载最新的 `.hap` 文件
2. 发送到手机（微信文件传输助手 / 数据线 / 任意方式均可）
3. 手机上使用「文件管理」找到该 `.hap`，点击安装
4. 首次安装需在系统弹窗中允许「未知来源应用」安装权限

### 方式二：电脑通过 hdc 安装（开发者）

```bash
hdc -t <设备序列号> install -r MyMix-v2_v1.0.0-test.N.hap
hdc shell aa start -a EntryAbility -b com.mymixnew.myapplication
```

> 覆盖安装请务必带 `-r`，否则会报安装失败。

## 版本号规则

格式：`v1.0.0-test.N`

- `1.0.0` 对应 `AppScope/app.json5` 中的 `versionName`
- `test` 表示测试构建（`buildMode=debug`）
- `N` 为递增的测试包序号，**数字越大越新**

装包后可在 **全局设置 → 关于** 中核对：

| 项目 | 说明 |
| --- | --- |
| 版本号 | `1.0.0 (1000000)` |
| 徽标 | 橙色「测试版」= debug 构建；绿色「正式版」= release 构建 |
| 安装时间 | 该包的实际安装时刻。**装完新包后请核对这项刷新了**，否则说明没装成功 |
